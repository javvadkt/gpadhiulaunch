# GPA-DHIU landing page

Static landing page with a short launch screen. Open `index.html` to preview.

## Files
- `index.html`: launch screen and landing page
- `styles.css`: layout, colours, type
- `script.js`: launch sequence and mobile menu

## Presenting
- Open `index.html?ceremony&guest=Dr.%20Name` to show the launch screen with the guest's name.
- The launch screen appears once per browser. Add `?ceremony` to the URL to show it again.
- Press Esc, or choose "Skip to website", to go straight to the page.

## Deploying
This is a standalone starter and does not change the live Vercel project. To make it the home page, add it as the `/` route of the existing app and keep the dashboard on its own route. Back up the current app first.
